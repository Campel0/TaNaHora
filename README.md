# TaNaHora

Sistema para gerenciamento e acompanhamento de medicamentos.

## Objetivo

Auxiliar pacientes no controle de medicamentos, evitando esquecimentos e melhorando a adesão ao tratamento.

---

## Funcionalidades

- Cadastro de usuário
- Login
- Recuperação de senha
- Cadastro de medicamentos
- Notificações de horário
- Registro de status (Tomado/Pular)
- Consulta de histórico

---
